# BestStreamersMoments Clipper — website

Static site for BestStreamersMoments Clipper: homepage, Privacy Policy and
Terms of Service. Plain HTML and one stylesheet, no build step, no
dependencies, no tracking.

Published with GitHub Pages from the `main` branch:
<https://grtling0.github.io/beststreamersmoments-website/>

| Page | Path |
|---|---|
| Home | `index.html` |
| Privacy Policy | `privacy.html` |
| Terms of Service | `terms.html` |

The Privacy Policy describes how the Clipper application actually behaves:
anonymous read-only Twitch chat, local recording and transcription, OAuth
tokens stored only on the operator's machine, and uploads sent straight from
that machine to the platform.
